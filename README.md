# 提瓦特冒险家协会 · 委托服务平台

业务骨架对标黑马「苍穹外卖」，把外卖换成原神世界观的委托服务。
用 FastAPI 重写（不是照抄 Java），并做了三处改造：抢单并发正确性、状态机显式化、AI 派单。

## 核心设计

- **订单状态机**：9 状态 / 15 事件 / 16 条合法转移 / 135 种组合全覆盖测试
- **抢单并发**：SQL CAS（`WHERE status='待接单' AND adventurer_id IS NULL`）+ Redis 锁减少无效竞争
- **支付幂等**：靠 `out_trade_no` 唯一索引，不靠锁
- **价格快照**：订单明细存下单时的价格，服务项改价不影响历史订单
